# ЛПР15 — Кореляція Пірсона та пряма регресії

## Тема роботи
Знаходження вибіркового рівняння прямої регресії за експериментальними даними.

## Виконані варіанти
- Варіант 6.7
- Варіант 6.8

## Завдання
За даними п’яти спостережень над величинами X та Y потрібно знайти вибіркове рівняння прямої регресії:

y = ax + b

Також потрібно побудувати графік, на якому показано експериментальні дані та пряму регресії.

## Результати

### Варіант 6.7

Рівняння регресії:

y = -0,74x + 5,92

Коефіцієнт кореляції Пірсона:

r ≈ -0,832

Висновок: між X та Y існує сильний обернений лінійний зв’язок.

### Варіант 6.8

Рівняння регресії:

y = -0,74x + 7,50

Коефіцієнт кореляції Пірсона:

r ≈ -0,826

Висновок: між X та Y також існує сильний обернений лінійний зв’язок.
